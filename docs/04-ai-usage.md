# AI 辅助使用与个人贡献

本项目使用 AI 辅助设计、实现和文档整理。候选人负责确认选题与技术取舍、选择模型服务、配置本地密钥，并亲自完成代码验证。实现主体由 AI coding 助手生成，以下分开记录个人工作与 AI 辅助范围。

## 工具与使用范围

| 工具或组件 | 使用范围 |
| --- | --- |
| AI coding 助手 | 选题分析、方案设计、Python 代码与测试生成、问题排查、文档整理 |
| DeepSeek Flash（deepseek-flash） | 项目运行时的 Agent 决策模型，依据工具观察选择动作；不是离线脚本替身 |
| 离线策略替身 | 在 --mode mock 下验证调用循环、工具和状态边界，不作为真实模型决策证据 |

AI 辅助完成的具体工作：

- 设计输入输出、四个业务工具、自定义 Runner、确认边界、SQLite 事务与幂等策略。
- 编写模型 HTTP 适配、CLI、Trace、数据与源码指纹、合成资料和自动测试。
- 根据真实运行与代码评审修正保存错误覆盖、授权窗口判断、结束反馈和评估断言。
- 执行自动化测试、离线评估、真实 API 评估及受控自纠探针，并保留实际输出。
- 依据官方文档核对 API 参数，处理本地 CA 配置，整理失败原因和限制。
- 按候选人要求，依据项目中的实际问题协助组织复盘与学习收获文字。

## 候选人个人贡献

| 工作 | 已确认的实际参与 |
| --- | --- |
| 需求和范围 | 确认选择第 1 题，优先完成审核、排期、确认和草稿保存核心链路 |
| 技术选择 | 确认采用原生轻量 Runner，选择 DeepSeek Flash 作为运行时模型 |
| 接入准备 | 亲自配置本地 API 密钥并授权真实模型验证 |
| 验证 | 亲自完成代码验证，检查项目运行与实现效果 |
| 改进决策 | 根据评审结果确认修复状态问题、增加结束自纠，并精简提交材料 |

候选人的验证参与由本人确认。仓库中的自动化报告是项目程序实际执行产生的记录；个人验证职责和自动化运行结果分别陈述，不把 AI 编写或执行的全部工作归为候选人独立手写、手工生成。
